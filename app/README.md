# Perch

Perch is a macOS menu bar app for saving and restoring window layouts across multiple displays.

This project lives in the repository's `app/` directory. Run the commands below from this directory.

The app runs as a menu-bar utility. It saves visible windows into named layouts, persists them to disk, and restores matching live windows later through the macOS Accessibility API.

- Xcode macOS app project generated by XcodeGen
- SwiftUI app lifecycle
- menu-bar-only configuration through `LSUIElement`
- deployment target macOS 14.0 Sonoma
- Accessibility permission request flow
- visible-window capture and display UUID mapping
- layout persistence in Application Support
- user-managed layouts with restore shortcuts
- optional prompt-based or automatic restore at startup, after wake and display changes
- launch-at-login and menu bar label preferences
- AX-based restore with title matching and retry verification
- runtime UI language switching (Czech, Slovak, English, Spanish, German)

## Usage

Perch appears in the macOS menu bar as `Perch`.

- Save layout 1-9 by order: `Command` + `Option` + `Shift` + `1...9`
- Restore layout 1-9 by order: `Command` + `Option` + `1...9`
- Custom restore shortcuts can be recorded per layout in Settings.

Settings also let you create, rename, and delete layouts, toggle launch at login, and hide the `Perch` text label so only the menu bar icon remains.

The first save or restore requires Accessibility permission. Use the Perch menu item `Grant Accessibility Permission...` if macOS has not granted it yet.

## Build and Run

Generate the Xcode project:

```bash
xcodegen generate
```

Build and launch the app:

```bash
./script/build_and_run.sh
```

Use `./script/build_and_run.sh --build-only` to prepare a debug app without
launching it. The script no longer terminates an existing Perch process; quit
that process when you are ready to run the debug build.

Build a signed release app and zip:

```bash
./script/build_release.sh
```

The release script requires a `Developer ID Application` signing certificate. To submit and staple a notarized build, first configure a `notarytool` keychain profile and then run:

```bash
PERCH_NOTARY_PROFILE=perch-notary ./script/build_release.sh notarize
```

Build a signed DMG for distribution:

```bash
PERCH_NOTARY_PROFILE=perch-notary ./script/build_dmg.sh notarize
```

See `docs/release-checklist.md` before publishing a public build.

Run tests:

```bash
xcodebuild test -project Perch.xcodeproj -scheme PerchModelTests -destination 'platform=macOS' -derivedDataPath build/DerivedData
```
