# Security policy

## Supported versions

Security fixes target the latest published Perch release and the `main`
branch. Older releases may require updating to receive a fix.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[hello@codeandlive.cz](mailto:hello@codeandlive.cz) with:

- the affected Perch version and macOS version;
- reproduction steps or a proof of concept;
- the expected impact; and
- whether the report may be acknowledged publicly after a fix.

Please avoid sharing real window titles, saved layouts, signing material, or
other private data. This is a spare-time project, so there is no guaranteed
response deadline, but security reports will be prioritized.
